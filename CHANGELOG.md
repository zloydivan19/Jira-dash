# Changelog — Jira PM Radar

All notable changes to this project are documented here.

---

## [v1.15.0] — 2026-04-01

### Fixed
- **Данные на вкладке "Контроль оценки" сохраняются при F5** — `issues` и `slaMap` записываются в `sessionStorage` и восстанавливаются при перезагрузке страницы; фильтры колонок также сохраняются
- **Фильтр-дропдаун в таблице оценки работает корректно** — исправлена проблема с чекбоксами (закрывались при каждом клике); дропдаун вынесен на уровень `EvaluationTab`, используется `useRef` для стабилизации колбэка `onClose`
- **Перенос текста по словам** — ячейки таблицы оценки теперь переносят длинный текст по словам (как на вкладках CR и Bugs)
- **Изменение ширины колонок** — добавлен ресайз колонок мышью с сохранением в `localStorage`
- **Сортировка и фильтрация** — поведение таблицы полностью приведено к стандарту вкладок CR / Ошибки

## [v1.14.0] — 2026-04-01

- **Кастомные поля для "Контроль оценки"** — в боковой панели вкладки "Поля" добавлен третий переключатель "Контроль оценки"; добавленные поля появляются в таблице как дополнительные колонки с сортировкой и фильтром через ▾; поля автоматически запрашиваются у Jira при загрузке задач

## [v1.10.0] — 2026-04-01

### Added

- **Фильтр по виду доработки** — дропдаун появляется когда есть хотя бы одно значение; уникальные значения берутся из загруженных задач

## [v1.9.0] — 2026-04-01

### Added
- **Столбец "Статус по SLA"** в таблице "Контроль оценки" — цветной бейдж с текстом: "Всё по плану" / "Скоро дедлайн" / "SLA нарушен" / "На паузе" / "Оценена"

## [v1.8.0] — 2026-04-01

### Added
- **"Выбрать всех" / "Снять все"** в мультиселекте — кнопки появляются после загрузки списка во всех фильтрах (менеджеры, клиенты, исполнители, авторы)
- **Сортировка в таблице "Контроль оценки"** — клик по заголовку любой колонки сортирует по возрастанию/убыванию; активная колонка подсвечивается; по умолчанию — по SLA (убывание)
- **Фильтры в таблице "Контроль оценки"** — панель фильтров под тулбаром: выпадающие списки по менеджеру и статусу; кнопка "Сбросить фильтры"; счётчик "N из M задач"

---

## [v1.7.0] — 2026-04-01

### Added
- **Мультивыбор менеджеров на вкладке "Контроль оценки"** — можно выбрать нескольких PM для загрузки задач
- **Сохранённые виды для вкладки "Контроль оценки"** — кнопка "+ Сохранить этот вид" появляется после загрузки данных, предлагает ввести имя (Enter/Escape), сохраняет список менеджеров; виды отображаются в боковой панели и загружаются одним кликом
- **Отдельное состояние менеджеров для eval-вкладки** — выбор менеджеров на вкладке оценки больше не пересекается с фильтрами CR-вкладки

## [v1.6.0] — 2026-04-01

### Added
- **Фильтр по клиентам на вкладке Задачи/Ошибки** — загружает список клиентов из `cf[12601]` по dev-проектам, инжектирует в текущий `jqlBugs`
- **Анимация загрузки на кнопках `↻ Загрузить`** — кнопка вращается и показывает "Загрузка..." пока идёт фетч
- **Toast-уведомления для всех фильтров:** при старте загрузки показывает "Загрузка может занять около минуты...", по завершении — "✓ Загружено N"

## [v1.5.0] — 2026-04-01

### Added
- **Кнопка "↻ Обновить"** в тулбаре таблицы — перезагружает данные по текущему JQL **без сброса фильтров колонок**

### Fixed
- Фильтры колонок таблицы теперь сохраняются в `sessionStorage` и восстанавливаются при F5
- При нажатии "Загрузить задачи" фильтры сбрасываются (полная перезагрузка) — поведение сохранено намеренно

---

## [v1.4.0] — 2026-03-31

### Added
- **Сохранённые запросы ("Мои запросы")** — сохранять/загружать/удалять именованные JQL + набор полей отдельно для вкладок CR и Bugs
- Лимит 20 сохранённых запросов на вкладку (старые удаляются автоматически)

### Fixed
- Все фильтры (клиент, автор CR, менеджер, исполнитель, автор Bugs) теперь **инжектируют условие в текущий JQL**, а не заменяют его целиком
- Фильтр по клиенту больше не добавляет `cf[12606] = currentUser()` — показывает задачи по клиенту у всех менеджеров
- Менеджер-фильтр заменяет только `cf[12606]`-условие, сохраняя статусы, даты и остальные условия

## [v1.2.0] — 2026-03-25

### Added
- **Вкладка "Задачи/Ошибки"** — отдельная таблица для dev-команды по проектам SRTZ, SRTB, SRTS, SR, HW, SCOC, SCOD
- Шаблоны для вкладки Bugs: все ошибки, критические, блокеры, задачи в работе, без исполнителя
- Фильтр по исполнителю и автору на вкладке Bugs
- Фильтр по автору (репортеру) на вкладке CR — инжектируется во все шаблоны
- **Session persistence** — данные таблицы сохраняются при F5 (sessionStorage, раздельно по вкладкам браузера)
- Ребрендинг: продукт переименован в **Jira PM Radar**, версия `v1.0 / by PM Fenix Team`
- Раздельные наборы полей для CR и Bugs (переключатель в табе "Поля")
- Сохранение ширины колонок в localStorage
- Сворачиваемый сайдбар (44px полоска с кнопкой `›`)
- CSV-экспорт: URL задачи как обычный текст (Excel делает кликабельным автоматически)

### Fixed
- JQL-шаблоны переведены на английские названия типов и приоритетов (`Bug`, `Story`, `Blocker`, `Critical`, `Major`)
- Фильтр колонок: все значения отмечены по умолчанию, кнопки "Выбрать все" / "Снять все"
- Данные CR и Bugs хранятся раздельно — переключение вкладок не сбрасывает таблицу
